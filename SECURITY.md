# Security

CoolSSH handles hosts, keys and passwords, so security reports get priority.

## Reporting a vulnerability

Report it privately through [GitHub security advisories](https://github.com/dortanes/coolssh/security/advisories/new). Do not open a public issue for it.

Include what you found, the version or commit, your platform, and the steps that show it. You will get an answer once the report has been reviewed, and credit in the release notes of the fix if you want it.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: how CoolSSH authenticates and checks host keys, how it stores passwords, passphrases and keys, the terminal's handling of what a server sends, and the release artifacts.

Out of scope: an attacker who already controls the computer or the user's account on it.
